# CivicAI backend dependencies.
#
# This is the SINGLE canonical install manifest for the backend. Install
# with:    pip install -r requirements.txt
#
# BigQuery is deliberately NOT here -- it is optional and has its own
# requirements-bigquery.txt, which this file does not duplicate.
#
# Version floors are used instead of exact pins. The repo previously pinned
# fastapi==0.115.0 / SQLAlchemy==2.0.35 / pandas==2.2.2, which are older than
# the versions the team is actually running; installing those pins would
# DOWNGRADE a working environment. Floors keep the file honest about what is
# required while letting pip resolve to what is already installed.
#
# Test-only dependencies (pytest, httpx) are included because the backend
# test suite is part of the product: `pip install -r requirements.txt` must be
# enough to run `pytest`.
